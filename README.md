# Any Weapon You Want!

Одностраничный интернет магазин с каталогом вооружения из разных стран

## Возможности

- добавление, сортировка, фильтры и удаление из корзины
- хранение корзины в local storage
- адаптивное оформление для разных девайсов

## Технологии

HTML, CSS, JavaScript

## Запуск 

Клонируйте репозиторий и откройте `index.html` в браузере

или посетите деплой: https://yaroslav1810.github.io/Web_1_shop/
